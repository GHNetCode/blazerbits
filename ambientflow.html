AmbientFlow.scr has been created to render flowing waves across your entire desktop, that has been designed to use minimal CPU and GPU usage (depending on settings set) in addition to spanning across more than 1 monitor. To save previous settings you can copy the AmbientFlow.ini file located in the same directory as the AmbientFlow.scr file which will appear after the settings have been applied by clicking the “OK” button on the screensaver settings dialogue screen.

Reference configuration

Example performance

Measured on an HP ProBook 440 G6 laptop driving two 24″ monitors: ~1% CPU and ~16% GPU with the settings below.

  • FPS 30
  • ResolutionScale 0.3
  • Speed 1.51
  • MaxOffscreenSeconds 0
  • WaveCount 4
  • Amplitude 1.1
  • Wavelength 1.94
  • Thickness 17.9
  • Brightness 1.19
  • SharpLines false
  • DarkTheme true
  • Fluidity 1
  • WaveTravel 0.96
  • RandomStart true
  • ColorRed true
  • ColorOrange true
  • ColorYellow true
  • ColorGreen true
  • ColorBlue true
  • ColorIndigo true
  • ColorViolet true
  • SpanMonitors true
  • RandomizeColors true

Getting started

Three steps, about a minute

No installer, no wizard, no reboot. AmbientFlow is a standard Windows screensaver — it just lives in a single file.

Download the file

Grab AmbientFlow.scr from the button at the top of this page. It's a self-contained binary — everything it needs is inside.

Install it

Right-click the downloaded file and choose Install. Windows will place it in the screensaver list automatically. (You can install it from anywhere for example in My Documents or %appdata%\ScreenSavers if you prefer.)

Pick it in Screen Saver Settings

Open Settings → Personalisation → Lock screen → Screen saver, choose AmbientFlow, and click Settings to fine-tune the look with a live preview.
