1. Ensure "screen saver Settings" is closed.
2. copy "AmbientFlow.scr" into "%appdata%\ScreenSavers" for example, where it can stay..
3. right click on the AmbientFlow.scr file and click install.
4. open the Screen Saver settings and you should find AmbientFlow listed. Enjoy.
Note: The "Reset to defaults" has been optimized for performance. (using minimal GPU\CPU as possible..)
